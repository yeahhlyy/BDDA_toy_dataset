# BDDA_toy_dataset
Due to copyright and ethical constraints on the full raw data, we provide a de-identified "BDDA toy dataset" in our repository for methodology verification.

## toy_train_log.json
A subset of the training set, where each element contains fields such as 'name', 'Task', 'Person', 'X', 'Y', and 'T' (representing the pre-processed gaze point data). 

## toy_image_features
It contains the corresponding extracted image feature files.
